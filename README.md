# ボドゲ勝率計算

GitHub Pages で公開する、対局記録・勝率確認用の PWA です。公開 URL は `https://tomotomo20060202-beep.github.io/boardgame-winrate/` です。

## ホーム画面への追加

HTTPS でサイトを開き、ブラウザーの「ホーム画面に追加」または「アプリをインストール」を選択してください。対応ブラウザーでは、インストール後はアプリ画面で起動します。

## オフライン利用とデータ

Service Worker がアプリ画面、manifest、アイコンをキャッシュするため、一度オンラインで開いた後はアプリをオフラインでも起動できます。対局記録と設定は従来どおりブラウザーの `localStorage` に保存され、PWA 化によって保存形式は変更されません。ブラウザーのデータ消去や別ブラウザー・別端末への移行では記録も消えるため、必要な記録は別途控えてください。

アプリシェルのキャッシュを更新するときは `service-worker.js` の `CACHE_NAME` のバージョンを上げてください。新しいシェルを事前キャッシュしてから旧バージョンの同アプリ用キャッシュだけを削除します。
